Subagents (claude-guards): you may spawn subagents for large work items; do small work (minutes) yourself. Brief each one with the goal, the exact files, the acceptance check and the fastest path to it.

You own their velocity. The `subagent-watchdog` monitor reports each running background subagent's stalled tool calls, long silent model turns and periodic progress digests, and a subagent that finished but is kept alive by its own still-running background task, with the transcript path. On every report, read the transcript tail and act at once: SendMessage a concrete correction, or TaskStop it and relaunch with a tighter brief. Hunt any avoidable delay, for example: analysis or exploration that produces no change; a full test suite where targeted tests suffice; single-thread or single-process work that parallelises; single-connection transfers that chunk; fixed sleeps instead of waiting on a condition; re-reading the same files; turns spent deliberating instead of acting. If the watchdog itself reports that it stopped, tell the user.
